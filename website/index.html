FAQ

开始之前，你可能想知道。

Magic Printer 会把文件上传到云端吗？＋

不会。默认情况下，WEB 服务、文件处理、打印记录和任务队列都运行在安装 Magic Printer 的电脑上。

为什么 Word 和 Excel 预览需要 LibreOffice？＋

浏览器不能可靠地还原常见 Office 文档。Magic Printer 使用 LibreOffice 将文件转换为 PDF，让预览与最终打印尽可能保持一致。

可以从公网直接访问吗？＋

项目首期只面向本机和经授权的局域网。跨网络使用建议通过可信 VPN，不建议把本地打印服务直接暴露到公网。

可以在公司或商业产品中使用吗？＋

公共许可证只允许非商业使用。公司内部部署、商业集成、销售、SaaS 或收费服务都需要版权持有人的单独书面授权。

现在可以下载吗？＋

项目目前处于需求与技术验证阶段。预览版发布后，安装包会出现在 GitHub Releases。

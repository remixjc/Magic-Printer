# Magic Printer 产品需求文档

- 文档版本：1.0
- 文档日期：2026-08-07
- 项目仓库：`remixjc/Magic-Printer`
- 当前状态：需求基线

## 1. 项目背景

用户需要在一台连接打印机的 Windows、macOS 或 Linux 电脑上运行 Magic Printer。应用常驻系统托盘，同时启动一个本地 WEB 服务。用户可以在本机或经授权的局域网设备上打开浏览器，上传文档、预览并提交打印任务；实际打印设备由桌面端设置中选定的打印机决定。

## 2. 产品目标

1. 提供一致、低门槛的三端安装和使用体验。
2. 将不同操作系统的打印能力封装为统一、安全的 WEB 打印流程。
3. 支持常见办公文件的上传、预览、打印和本地记录管理。
4. 对 E-safe（亿赛通）加密文件进行识别和阻断，避免无法读取的内容进入打印流程。
5. 通过 GitHub Actions 和 GitHub Releases 实现可重复构建、发布和应用更新。

## 3. 范围定义

### 3.1 首期范围

- Windows 10/11 x64；macOS 13+（Intel 与 Apple Silicon）；主流 x64 Linux 桌面发行版。
- 托盘常驻、设置窗口、打印机枚举与默认打印机配置。
- 本机访问；局域网访问作为可选能力，由用户明确开启。
- 图片、PDF、DOC/DOCX、XLS/XLSX 的上传、校验、预览和打印。
- 最近七天打印记录、本地删除、到期自动清理。
- 自动/深色/浅色主题。
- 开机启动。
- 环境检测、LibreOffice 安装引导及预览能力降级。
- GitHub Releases 检查更新；下载完成后提示重启安装。

### 3.2 暂不纳入首期

- 公网云打印、用户账号云同步和多租户管理。
- 移动端原生应用。
- 打印计费、配额、审批流和企业组织架构。
- 文档在线编辑。
- 打印机驱动自动安装。
- 在应用内绕过或解除 E-safe 加密。

### 3.3 发布与许可边界

- 源代码和官方构建产物对非商业用户免费开放。
- 项目采用 `PolyForm-Noncommercial-1.0.0`，允许非商业目的下学习、修改和分发。
- 未经版权持有人书面许可，禁止企业内部使用、商业产品集成、销售、SaaS、收费服务和其他商业用途。
- 官网、README、安装界面和 About 页面必须展示许可证名称、版权归属及非商业限制。
- 因许可证限制商业使用，对外描述采用“免费、源码可用、仅限非商业使用”，避免错误宣称为 OSI 开源软件。

## 4. 用户角色与典型场景

### 4.1 设备管理员

- 安装并启动应用。
- 选择允许 WEB 端使用的打印机。
- 配置局域网访问、主题、开机启动与更新策略。
- 查看服务状态、地址和依赖检测结果。

### 4.2 打印用户

- 在浏览器打开打印页面。
- 上传并预览文档。
- 设置份数、页码范围、单双面、彩色/灰度、纸张和方向等打印参数。
- 提交任务并查看结果。
- 查看和删除本机最近七天的打印记录。

## 5. 业务流程

### 5.1 首次启动

1. 应用检测操作系统、可用打印机和预览依赖。
2. 若没有打印机，设置页展示明确提示，WEB 端禁用提交打印。
3. 若缺少 LibreOffice，询问是否前往官方下载页或执行系统支持的安装命令。
4. 用户拒绝安装时，Office 文件仍可按平台能力尝试打印，但不显示预览入口，并清楚提示风险；图片和 PDF 预览不受影响。
5. 用户选择打印机并保存。
6. 应用启动 WEB 服务，显示本机地址；局域网地址仅在开启局域网访问后显示。

### 5.2 上传、预览与打印

1. 用户选择或拖入文件。
2. 服务校验扩展名、MIME、文件头、大小和文件名安全性。
3. E-safe 检测器检查文件；确认或高度可信地判定为加密时，弹窗提示“文件已被 E-safe 加密，请解密后重新上传”，取消预览并禁止打印。
4. 图片/PDF 直接生成预览；Word/Excel 通过 LibreOffice 转换成临时 PDF 后预览。
5. 用户选择打印参数并确认。
6. 服务创建任务快照，使用桌面端当前配置的打印机执行打印。
7. 页面实时展示排队、转换、打印中、成功或失败状态。
8. 临时源文件和预览产物按策略删除；记录保留七天。

### 5.3 打印机切换

1. 管理员在设置界面选择打印机并保存。
2. 新任务使用新打印机；已经进入打印阶段的任务不迁移。
3. 若已选打印机离线或被删除，应用显示错误并暂停新任务，禁止静默回退到其他打印机。

## 6. 功能需求

### FR-01 跨平台安装

- Windows：提供签名安装包，目标格式 NSIS `.exe`；可选 MSI 作为后续能力。
- macOS：提供签名并公证的 `.dmg`，分别构建 x64/arm64 或 universal 包。
- Linux：首选 AppImage，同时提供 `.deb`；后续按需求支持 RPM。
- 安装、升级和卸载不得删除用户记录，除非用户主动选择清除数据。

### FR-02 托盘与窗口

- 关闭设置窗口默认隐藏到托盘，不退出服务。
- 托盘菜单至少包含：打开打印页面、设置、服务状态、检查更新、退出。
- 退出操作需要停止接收新任务，并妥善结束或取消当前任务。

### FR-03 设置界面

- 显示打印机名称、系统标识、在线状态和默认标记。
- 选择一个活动打印机；保存前验证设备仍存在。
- 配置 WEB 服务端口、局域网访问、访问口令、主题、开机启动和自动更新。
- 展示依赖状态、数据目录、日志目录和应用版本。

### FR-04 WEB 服务与访问

- 默认监听 `127.0.0.1`，端口可配置且冲突时给出处理建议。
- 局域网模式监听明确选择的接口或 `0.0.0.0`，必须开启身份验证。
- 展示可复制的访问地址和二维码可作为增强项。
- 不承诺直接公网访问；公网场景要求 VPN 或经过安全配置的反向代理。
- 桌面应用退出后 WEB 服务必须停止。

### FR-05 文件支持

| 类别 | 首期格式 | 预览方式 | 打印标准路径 |
|---|---|---|---|
| 图片 | PNG、JPEG/JPG、WebP、BMP、TIFF | 浏览器/安全解码后预览 | 转为标准 PDF 后打印 |
| PDF | PDF | PDF.js | PDF 打印管线 |
| Word | DOC、DOCX | LibreOffice 转 PDF | 转 PDF 后打印 |
| Excel | XLS、XLSX | LibreOffice 转 PDF | 转 PDF 后打印 |

- 默认单文件上限建议 100 MB，可在配置中收紧。
- 首期一次提交一个文件；多文件批量任务列为后续增强。
- 文件格式以内容检测为准，不只依赖扩展名。
- 受密码保护、损坏、宏异常或转换失败的文件必须给出可理解的错误。

### FR-06 预览依赖与降级

- 图片与 PDF 预览属于内置能力，不依赖 LibreOffice。
- Word/Excel 预览依赖 LibreOffice。
- 启动时和用户上传 Office 文件前均可重新检测依赖。
- 安装引导必须在用户确认后执行；macOS/Windows 优先跳转官方安装页，Linux 可展示并在确认后执行适合发行版的安装命令。
- 未安装时，WEB 端隐藏 Office 预览控件并显示“当前设备未启用 Office 预览”。
- 是否允许“无预览打印 Office 文件”应作为管理员配置，默认关闭，避免版式不确定造成误印。
- 当 LibreOffice 不可用时，能力接口应返回当前系统的官方下载地址和建议安装命令，客户端可据此提供安装引导；应用不得在未获用户确认时静默安装系统软件。

### FR-07 E-safe 加密识别

- 通过统一 `EncryptionDetector` 接口接入亿赛通官方 SDK、客户端命令行或企业提供的检测能力。
- 检测结果至少包含：未加密、已加密、疑似加密、检测不可用。
- 已加密：禁止预览和打印，提示用户在授权环境中解密后重试。
- 疑似加密或检测不可用：默认阻断 Office 文件打印，并展示管理员可诊断信息；策略可配置但必须记录。
- 禁止尝试破解、绕过或自动解密文件。
- 在取得厂商正式接口前，不将“100% 准确识别”作为验收承诺。

### FR-08 打印参数与执行

- 基础参数：份数、全部页/页码范围、纵向/横向、纸张、彩色/灰度。
- 双面、装订、纸盒等能力仅在打印机驱动报告支持时显示。
- 参数必须在服务端再次校验。
- 同一台打印机默认串行执行任务，避免并发调用驱动导致状态不确定。
- 每个任务保留提交时的打印机与参数快照。

### FR-09 打印记录

- 记录字段：任务 ID、原始文件名、文件类型、页数（可得时）、打印机、参数摘要、状态、错误摘要、创建/完成时间。
- 默认不长期保存原始文档；记录中不得保存文档内容。
- 记录仅存本机，默认保留七天，按完成时间自动清理。
- 用户可单条删除或全部清空。
- “删除记录”同时清理属于该任务且尚存的临时文件。

### FR-10 主题与界面

- 主题选项：自动、深色、浅色；自动跟随系统。
- 视觉参考 VS Code 默认 Dark Modern / Light Modern 的色彩层级，但不直接复制受保护资产。
- WEB 主布局建议：左侧任务/记录导航，中间上传与预览区，右侧打印设置和提交区，底部状态栏。
- 提交打印前必须让用户看到目标打印机、份数和关键参数。
- 支持键盘操作、清晰焦点状态和常见屏幕尺寸的响应式布局。

### FR-11 开机启动

- 设置页提供开关，默认关闭。
- 开机启动后应用默认进入托盘，不主动弹出窗口。
- 启动失败应写入日志，并在下次打开界面时提示。

### FR-12 更新

- 稳定版从 GitHub Releases 获取更新。
- 支持手动检查与可配置的启动后检查。
- 下载完成后提示用户重启安装；不在打印任务执行期间强制退出。
- 更新失败时保留当前可运行版本并允许重试。
- Linux AppImage 支持应用内更新；DEB/RPM 通常由包管理器更新，不承诺同样的无缝体验。

## 7. 非功能需求

### 7.1 安全

- WEB 服务默认仅本机可访问。
- 局域网模式必须启用强随机口令或配对码，并使用短期会话。
- 所有上传文件使用随机内部文件名并存入应用私有目录，防止路径穿越。
- 设置上传大小、请求频率、并发转换和打印队列限制。
- 不执行文档宏；LibreOffice 转换使用隔离的临时用户配置目录和超时。
- API 执行 CSRF、Origin/Host 校验；敏感值不得写入普通日志。
- LAN 明文 HTTP 的风险必须在界面提示；企业场景建议配置 HTTPS 反向代理/VPN。

### 7.2 稳定性与性能

- 常驻空闲内存目标：不高于 250 MB，具体以原型测试为准。
- 普通页面首次加载目标：本机环境 2 秒内可交互。
- 转换任务有超时、取消和残留进程回收机制。
- 应用异常重启后，将未完成任务标记为中断，不自动重复打印。
- 数据库写入采用事务；任务状态转换可审计。

### 7.3 隐私

- 文件与记录默认不上传到任何云端。
- 默认打印完成后立即删除源文件和预览缓存；失败文件最多短期保留用于重试，并明确展示策略。
- 日志仅记录文件名的脱敏形式或哈希，生产模式不记录文件内容。

### 7.4 可维护性

- 平台打印、依赖检测、加密检测和自动启动均通过接口隔离。
- API 使用共享 schema 生成前后端类型。
- 核心模块需要单元测试；上传到打印的主路径需要端到端测试。

## 8. 验收标准

1. 三个平台均能安装、启动、最小化到托盘并正常退出。
2. 能枚举系统打印机、保存选择，并确保 WEB 新任务只发送到该打印机。
3. 图片/PDF 可上传、预览和打印；Word/Excel 在 LibreOffice 可用时可转换预览和打印。
4. 缺少 LibreOffice 时桌面端给出安装选择，WEB 端按配置隐藏 Office 预览并阻止默认的无预览打印。
5. 经官方检测接口确认的 E-safe 加密文件无法预览和打印，提示语准确。
6. 打印任务状态可追踪；应用崩溃恢复后不会重复打印。
7. 七天前的记录自动删除，用户能手动删除记录。
8. 自动、深色、浅色主题均可切换并持久化。
9. 开机启动开关在三个系统上生效。
10. GitHub Actions 能构建三个系统的安装包；带版本标签的流程能创建 Release 草稿并上传产物。

## 9. 待确认事项

以下问题需要在原型阶段形成正式决策：

1. 亿赛通产品的具体版本、部署模式，以及是否能提供官方 SDK/CLI 和测试样本。
2. “远程访问”是否仅指同一局域网；若包含公网，需要单独的身份、TLS、域名和运维方案。
3. Office 未安装时是否允许无预览直接打印，建议默认不允许。
4. 需要支持的最大文件大小、最大页数和并发用户数。
5. 首批重点适配的打印机品牌、型号与高级参数。
6. 是否需要代码签名证书、Apple Developer 账号及 Linux 仓库分发。
7. 是否要求完整中英文界面与无障碍等级。

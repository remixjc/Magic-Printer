## 为什么选择这个许可证

项目希望将源代码免费提供给个人、学校、研究机构和非营利组织使用，同时禁止未经授权的商业利用。MIT、Apache-2.0、BSD 和 GPL 等标准开源许可证都允许商业使用，不能满足这一目标；Creative Commons 的 NC 系列也不推荐用于软件代码。

PolyForm Noncommercial 专门面向软件，允许非商业目的下使用、研究、修改和分发，因此更符合 Magic Printer 的定位。

由于该许可证限制商业用途，Magic Printer 在严格法律分类上属于“源码可用（source-available）”项目，而不是 OSI 定义下的开源软件。项目介绍中应使用“免费、源码开放、仅限非商业使用”等准确表述。

## 免费允许的使用

- 个人学习、研究、实验和兴趣项目。
- 在个人设备或家庭网络中运行 Magic Printer。
- 为非商业目的阅读、修改和构建源代码。
- 教学、学术研究、公益组织、公共研究、公共安全或政府机构使用。
- 在保留完整许可证和 Required Notice 的前提下，非商业地分发原版或修改版。
- 向项目提交 Issue、文档和代码贡献。

## 未经书面许可禁止的使用

- 在营利性公司内部部署或用于日常业务打印。

- 销售、出租、收费分发安装包或修改版本。

“没有直接收费”不必然代表非商业。例如，企业内部使用、广告支持的服务、用于赢利业务的配套工具，通常都应视为商业场景。无法确定时，应在使用前联系版权持有人。

## 修改与再分发要求

非商业修改和再分发时必须：

1. 附带完整的 `LICENSE` 文件或许可证正文地址。
2. 保留以下 Required Notice：

   ```text
   Required Notice: Copyright (c) 2026 remixjc. Magic Printer is licensed for noncommercial use only.
   ```

3. 清楚说明修改内容，避免让用户误认为修改版由官方维护或认可。
4. 不得把项目重新许可为 MIT、Apache-2.0、GPL 等其他许可证。
5. 若公开分发 fork，建议更换名称和图标，避免与官方 Magic Printer 混淆。
